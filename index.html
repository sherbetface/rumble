🔊 Crowd & bell sounds

  
Each button has a built-in sound. You can swap any of them for an audio file (MP3, M4A or WAV) or a YouTube link. On the admin device, your choices go into the master list, so every device gets them. Free crowd and arena recordings are on the BBC Sound Effects website and Pixabay.

  
These sounds are managed from the admin device.

🛠️ Admin hub

  

  
The master list holds every wrestler’s name, photo, Spotify link, start time, style and YouTube link, and lives in your GitHub rumble folder. Every device loads it each time Rumble opens. Only a device with the admin key can change it. That can be this iPad, your iPhone, or a laptop: just open your Rumble address in its browser.

  
1 · Make a key (once)

  
    
    
  1. On github.com, tap your profile picture → Settings.
    2. 
    
  2. Scroll to the bottom of the left-hand menu → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. 
    
  3. Name: Rumble admin. Expiration: pick the longest option.
    4. 
    
  4. Repository access: Only select repositories → choose rumble.
    5. 
    
  5. Permissions → Repository permissions → Contents → Read and write.
    6. 
    
  6. Tap Generate token and copy it. It starts github_pat_.
    7. 
  

  
2 · Connect this device
